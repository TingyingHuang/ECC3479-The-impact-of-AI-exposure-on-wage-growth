## 01_aioe_by_anzsco.csv

Generated by `02_mapping_aioe_to_anzsco.py`. One row per 6-digit ANZSCO code.

Maps US AIOE scores into Australian occupation codes via SOC → ISCO-08 → ANZSCO 2022. Where one SOC maps to multiple ISCO codes the score is split equally to avoid double-counting.

| Variable | Description |
|----------|-------------|
| `anzsco_code` | 6-digit ANZSCO code |
| `anzsco_title` | Occupation title |
| `aioe_mean` | Mean AI exposure score across all mapping paths |
| `aioe_sum` | Sum of path contributions |
| `n_paths` | Number of SOC → ISCO → ANZSCO paths contributing |

> ANZSCO version note: crosswalk uses ANZSCO 2022; HILDA uses ANZSCO 2006. At the 2-digit level the two are structurally equivalent.

## 06_hilda_person_wave_panel.csv *(restricted)*

Generated by `05_build_hilda_minipanel.py`. One row per person per survey wave (all waves 2002–2024).

Raw extraction from HILDA Combined files. HILDA negative codes (−1 to −10) are sentinel values treated as missing in script 06.

| Variable | Description |
|----------|-------------|
| `xwaveid` | Cross-wave person identifier |
| `wave` / `year` | Wave letter; year = 2001 + (ord(wave) − ord('a')) |
| `jbmo62` | 2-digit ANZSCO 2006 occupation code |
| `wscmg` | Annual gross wages/salary — main/only job (continuous AUD, financial year) |
| `wscmga` | Imputed version of `wscmg` (fallback for missing) |
| `hgsex` | Sex (1 = male, 2 = female) |
| `hgage` | Age in years |
| `hhstate` | State of residence (ABS code 1–8) |
| `edhigh1` | Highest education level (1–10; 1 = postgrad, 10 = < Year 11) |

## 08_wages_ai_analysis_panel.csv *(restricted)*

Generated by `06_build_hilda_ai_analysis_panel.py`. One row per person-year, 2020–2024. Final model-ready panel.

**Wage cleaning:** uses `wscmg` (annual gross wages from main job, continuous AUD) with `wscmga` (imputed) as fallback; negative/zero values set to missing; rows with no valid pay dropped.

| Variable | Description |
|----------|-------------|
| `person_id` | Person identifier |
| `year` | Calendar year (2020–2024) |
| `occ_code` | 2-digit ANZSCO occupation code |
| `occ_major_group` | First digit of ANZSCO (major group 1–8) |
| `white_collar` | =1 if ANZSCO major group 1–4 |
| `blue_collar` | =1 if ANZSCO major group 5–8 |
| `ai_exposure` | Occupation-level AI exposure score (continuous, time-invariant). Range ≈ −1.47 to +1.93; negative = low AI exposure relative to sample mean. ~17% missing. |
| `annual_wage` | Harmonised positive pay in AUD |
| `log_wage` | log(`annual_wage`) — main outcome variable |
| `sex` | 1 = male, 2 = female |
| `age` | Age in years |
| `state` | State of residence (ABS code 1–8) |
| `edu` | Highest education level (1–10; 1 = postgrad) |
| `yr_2021` … `yr_2024` | Year dummies (base year = 2020) |
| `ai_x_yr2021` … `ai_x_yr2024` | `ai_exposure × yr_t` — interaction terms for β_t; NA where `ai_exposure` is missing |

**Model:**
```
log_wage_it = α + Σ_t β_t·(ai_exposure_i × yr_t) + γ·X_it + μ_i + ε_it
```
β_t = marginal wage return to AI exposure in year t relative to base year 2020. μ_i = individual fixed effect.
